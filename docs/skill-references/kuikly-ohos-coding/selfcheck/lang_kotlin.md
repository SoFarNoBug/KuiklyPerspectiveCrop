# 自检清单 · lang_kotlin（L1）

> 全文 SoT：`docs/skill-references/coding-norms/base/lang_kotlin.md`。本文件只摘「条款 + 什么算做到了」，判据细节以全文为准。
> 三态图例见同目录 `README.md`：`OK`（落点行号）/ `TODO`（不做 + 理由）/ `N/A`（一句判据）。

| # | 条款 | 什么算 `OK`（判据） |
|---|---|---|
| K1 | 不可变优先 | 能不改就用 `val`，未默认 `var` |
| K2 | 只读集合边界 | 对外声明 `List`/`Set`/`Map`，工厂用 `listOf`/`setOf`/`mapOf`；可变集合只在实现内部 |
| K3 | 空安全 | 可空显式 `T?`，优先 `?.`/`?:`/判空后智能转换（无隐式可空传递） |
| K4 | `!!` 纪律 | 无裸 `!!`；若必须用，紧邻一行注明"已校验/契约非空"；无链式 `a!!.b!!` |
| K5 | `Boolean?` 判等 | 写 `== true` / `== false`，未当非空 Boolean 用 |
| K6 | 平台类型不外泄 | Java 返回值/属性初值作为公开返回值时写了明确 Kotlin 类型（`String`/`String?`），未让 `T!` 推断进入公开 API |
| K7 | 命名（通则 + 两条例外） | 包全小写；类型 `UpperCamel`；函数/属性/局部变量 `lowerCamel`。**以下两条为例外，记 `OK` 不判违规**：①深层不可变常量 `SCREAMING_SNAKE`；②**私有成员变量一律 `_` 前缀**（`_items`），而局部变量/函数参数/公开属性/`companion` 常量**一律不加** `_`。本单新增的私有字段属**强制项**（只许 `OK` 或 `N/A`）；既有未触及字段不回填 |
| K8 | 函数形态 | 单表达式优先 `fun f() = …`；返回 `Unit` 省略类型 |
| K9 | 控制流 | `if`/`when`/`try` 优先作表达式；二分用 `if`、≥3 支用 `when` |
| K10 | 默认参数 vs 重载 | Kotlin 侧优先默认参数；会被 Java 调用时按 L3 互操作约定（如 `@JvmOverloads`） |
| K11 | lambda 可读性 | 嵌套 lambda 用显式参数名（不只 `it`）；无多层标号 return |
| K12 | 扩展可见性 | 扩展未做成无约束顶层公共扩展，可见性已收窄 |
| K13 | 类成员顺序 | 属性/init → 次构造 → 方法 → `companion`；重载相邻 |

## 搬运/抽方法时的附加要求

提方法、内联、整段复制时，被搬动的那段要**重新过一遍 K1–K13**（不得以"原本就这样"豁免），并把发现的既有缺陷按 SKILL §搬运登记（`carried-over:`）写进 changelog 或当轮修掉。
